    Method

    All models are called as plain base-model APIs: no tools, no retrieval, no agent loop, one stateless turn per task.

    Scoring

    • Judged (Foundational, Root-Cause, Report): rubric score 0–10 from an LLM judge, shown as %.
    • Rule-checked (STA, FM, ECO, ICC2, Innovus): exact command / answer checkers. Pass rate %.
    • pass@1: one sample. pass@5: five separate samples; any-correct for rule-checked tasks, mean score for judged tasks.
    • Overall: unweighted mean of the category scores, so every category counts equally regardless of size.

    Reading the results

    • LATEST models were run on 2026-09-23 (reasoning effort medium, 32K output cap) and judged blind by GPT-5.4-mini.
    • EARLIER models come from the paper's earlier evaluation, with a different judge for the three judged categories. Compare those categories within a round. Rule-checked categories use identical checkers in both rounds.
    • STA, ECO and Report have only 10–11 tasks each, so one task moves the score by about 9–10 points.
